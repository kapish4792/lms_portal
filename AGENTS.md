## Project Overview

- Root: `lms-portal/`

## Key Libraries

- **State**: `zustand` (one store per module, persisted to `localStorage`)
- **Video**: `video.js` (HLS/DASH, adaptive bitrate, custom controls)
- **UI**: `shadcn/ui` components in `src/components/ui/`
- **Utils**: `clsx`, `tailwind-merge`, `lucide-react`, `class-variance-authority`

---

## Architecture Notes

- **Tailwind v4**: Uses `@theme` in `src/app/globals.css` (CSS variables, no `tailwind.config.ts`)
- **shadcn/ui**: Base UI (not Radix), Nova preset, CSS variables enabled
- **TooltipProvider**: Required in `layout.tsx` — wrap children
- **Fonts**: Geist Sans + Geist Mono via `next/font/google`

## Design System Reference

See `../agent/ui/DESIGN_SYSTEM.md` for:
- Color roles (`brand-*`, `accent-*`, `success/warning/danger/pending`, `surface-*`, `text-*`)

## LMS Product Spec

See `../agent/app/lms-product-research.md` for:
- Role architecture: Super Admin, Org Admin, Dept Head, Instructor, Learner, Manager, Custom User Types
- Dedicated login per role (no in-app role switcher)

## Active Module Step Plan

### Module 27: Certifications (Proposed — spec §3.21, `agent/app/lms-product-research.md` and its split copy `agent/app/01-product-functional-specification.md`)

Newly specified module (added 2026-09-26, not part of the original TalentLMS/Udemy benchmarking). Issued by Instructor (own courses) / Manager (direct reports) / Org Admin (org-wide) after a learner completes a course — not automatic on completion.
